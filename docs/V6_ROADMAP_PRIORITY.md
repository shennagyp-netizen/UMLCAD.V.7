# V6 Roadmap Priority

Continue the V6 kernel roadmap to completion. Application/UI work is downstream and must not replace remaining kernel gates.

Current priority:

1. complete backend-neutral freeform curve/surface contracts;
2. complete native backend realization for those contracts;
3. close sweep/pipe, offset/healing, tessellation, and exchange gates;
4. strengthen topology/reference persistence and adversarial validation;
5. complete the V6 full regression/release gate.

The semantic mathematical layer remains UMLCAD-owned. External kernels such as OCCT are realization and conformance backends, never semantic authorities.
