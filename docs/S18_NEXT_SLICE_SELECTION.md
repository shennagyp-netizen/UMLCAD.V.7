# S18.x Next Slice Selection

The next S18.x implementation slice is selected from the remaining kernel gaps by the following order:

1. deterministic semantic tractability;
2. independent mathematical oracle availability;
3. meaningful native OCCT conformance;
4. direct contribution to the declared part-geometry-kernel boundary;
5. explicit fail-closed behavior outside the certified family.

The first target after the S19-labelled historical slices is generalized freeform surface boundary/intersection tracing only where a self-contained mathematical contract can be established. Unrestricted NURBS/NURBS tracing is not assumed; each certified family must remain explicit.
